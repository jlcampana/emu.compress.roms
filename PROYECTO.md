# Proyecto

Emudeck tiene una herramienta de compresión. La tengo instalada pero busca las roms en rutas fijas.

Lo que quiero es tener un script que sea capaz de hacer lo mismo que el Bulk Compression y con otro parámetro el Buld Decompression de la ruta actual en la que estoy.

Quiero que este script se pueda instalar directamente haciendo un curl http://raw.github.com/xxxxx | bash

Y que ese script de instalación sea capaz de detectar si estoy en Ubuntu o Fedora (el sistema actual es Fedora) e instale todas las dependencias necesarias para hacer funcionar el script.
